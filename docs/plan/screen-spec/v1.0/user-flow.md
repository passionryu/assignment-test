# User Flow v1.0

Status: Draft - Human approval 대기

## 메인 진입 흐름

```mermaid
flowchart TD
    A["로그인 후 메인 페이지 진입"] --> B["최상단 기록방 자동 선택"]
    B --> C["사이드바에 선택 방 기능 표시"]
    C --> D["프로필 확인"]
    C --> E["최신 알림 확인"]
    C --> F["전체 기록 캘린더 확인"]
```

## 방 내부 기능 흐름

```mermaid
flowchart TD
    A["사이드바: 방 리스트"] --> B["선택된 방"]
    B --> C["채팅"]
    B --> D["추억 게시판"]
    B --> E["미션 인증"]
    B --> F["편지"]

    C --> G["날짜 구분선 기준 대화 기록"]
    C --> H["대화 검색"]
    C --> I["날짜 이동"]

    D --> J["사진+글 카드 피드"]
    D --> K["추억 작성"]
    D --> L["추억 상세"]

    E --> M["진행중"]
    E --> N["승인 대기"]
    E --> O["완료"]
    E --> P["인증 올리기"]

    F --> Q["받은 편지함"]

    F --> S["편지 쓰기"]
```
