# Issue 31 Human QA

## Issue

- #31 `[Lv2 고도화] 템플릿 기반 책 미리보기 뷰어 구현`

## 구현 결과

- 기존 카드형 대표 페이지 목록을 책 페이지형 템플릿 미리보기 뷰어로 변경했다.
- 기록 선택에서 넘긴 `preview.contents` 데이터를 기준으로 커버, 목차, 선택 기록 페이지를 구성한다.
- 각 선택 기록은 타입, 제목, 본문 요약, 작성자, 날짜, 사진/댓글 수, 예상 지면 수를 미리보기 페이지에 표시한다.
- 좌우 화살표와 하단 썸네일 네비게이션으로 미리보기 페이지를 이동할 수 있다.
- 페이지 표기는 실제 PDF 확정본이 아니라 템플릿 예상 지면임을 알 수 있게 `3-4p 예상` 같은 표현을 사용한다.
- 예상 견적 패널과 `주문 요청하기` CTA는 기존 흐름을 유지했다.

## Human QA List

- `책 만들기`에서 방, 상품, 기간, 기록을 선택한 뒤 `미리보기/견적 계산`까지 진행한다.
- 미리보기 화면 제목이 `템플릿 책 미리보기와 예상 견적`으로 보이는지 확인한다.
- 중앙에 큰 책 페이지형 미리보기가 보이고, 오른쪽에는 예상 견적 패널이 유지되는지 확인한다.
- 커버 페이지에 책 제목, 방 이름, 기간, 상품/예상 페이지 요약이 표시되는지 확인한다.
- 목차 페이지에 추억/미션/편지/채팅 개수가 표시되는지 확인한다.
- 선택한 기록들이 기록 선택 단계의 구성 순서대로 미리보기 페이지와 하단 썸네일에 표시되는지 확인한다.
- 추억/미션/편지/채팅 타입별로 아이콘과 색상 블록이 다르게 보이는지 확인한다.
- 좌우 화살표 클릭으로 이전/다음 미리보기 페이지 이동이 되는지 확인한다.
- 하단 썸네일 클릭으로 해당 미리보기 페이지로 바로 이동되는지 확인한다.
- `3-4p 예상` 같은 페이지 범위가 기록의 예상 페이지 할당과 맞게 표시되는지 확인한다.
- `주문 요청하기` 버튼을 눌렀을 때 기존 주문 확인 modal 흐름이 유지되는지 확인한다.
