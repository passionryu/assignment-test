# Issue 32 Human QA

## Issue

- #32 `[Lv2 고도화] 주문 상태·내역·운영자 주문 관리 테이블 UI 구현`

## 구현 결과

- `주문 상태`, `주문 내역`, `운영자 주문 관리` 화면을 카드 목록 중심에서 테이블형 주문 관리 UI로 변경했다.
- 주문일 시작/종료, 상태, 검색어, 정렬, 표시 개수 필터를 지원한다.
- CSV 다운로드를 3종으로 분리했다: 현재 화면 CSV, 필터 전체 CSV, 선택 항목 CSV.
- 좁은 화면에서도 주문 목록을 카드로 바꾸지 않고, 테이블을 가로 스크롤하도록 구성했다.
- 일반 사용자 주문 상태/내역은 우측 상시 상세 패널 없이 전체 주문 테이블만 표시하고, 테이블 행 또는 `보기` 버튼 클릭 시 상세 모달을 연다.
- 운영자 주문 관리도 우측 상시 상세 패널 없이 전체 주문 테이블만 표시하고, 테이블 행 또는 `보기` 버튼 클릭 시 상세 모달을 연다.
- 주문 상세 모달은 기존 긴 콘텐츠 목록 대신 `책 만들기 > 미리보기`와 같은 템플릿 책 미리보기 UI로 담긴 콘텐츠를 확인할 수 있다.
- 주문 상세 모달의 상태 이력은 현재 단계까지 채워지는 가로 진행선과 하단 이력 목록으로 확인할 수 있다.
- 운영자 화면에서는 체크박스로 여러 주문을 선택하고, 다음 상태로 일괄 변경할 수 있다.
- 운영자 화면의 `처리 가능만` 필터를 제거하고, 필터 초기화 버튼 크기를 보조 액션에 맞게 줄였다.

## Human QA List

- 일반 사용자로 로그인한 뒤 `추억을 책으로 소장 > 주문 상태`에 진입한다.
- 주문 상태 화면에서 주문 목록이 카드가 아니라 테이블로 보이는지 확인한다.
- 주문일 시작/종료, 상태, 검색어, 정렬, 표시 개수 필터가 동작하는지 확인한다.
- `취소 가능만` 체크 시 취소 가능한 주문만 남는지 확인한다.
- `현재 화면 CSV`, `필터 전체 CSV`, `선택 항목 CSV` 버튼으로 파일 다운로드가 되는지 확인한다.
- 주문 행 본문 또는 `보기` 버튼을 클릭했을 때 넓은 상세 모달이 열리는지 확인한다.
- 상세 모달에서 주문 정보, 담긴 콘텐츠 템플릿 미리보기, 썸네일 이동, 예상 페이지/수량/총액이 보이는지 확인한다.
- 상세 모달에서 상태 진행선이 현재 상태까지 색으로 채워지고, 하단 상태 이력 목록에 변경 시각과 상태가 나열되는지 확인한다.
- 좁은 브라우저 폭에서 테이블이 카드로 변하지 않고 가로 스크롤되는지 확인한다.
- `추억을 책으로 소장 > 주문 내역`에서도 동일한 테이블, 필터, CSV, 상세 모달 흐름이 유지되는지 확인한다.
- 운영자 캐릭터로 진입해 운영자 주문 관리 화면이 우측 상세 카드 없이 전체 주문 테이블 카드 하나로 보이는지 확인한다.
- 운영자 화면 필터 영역에 `처리 가능만` 체크박스가 보이지 않는지 확인한다.
- 운영자 화면의 `필터 초기화` 버튼이 다른 입력 칸처럼 과하게 크게 보이지 않는지 확인한다.
- 운영자 주문 테이블 행 또는 `보기` 버튼을 클릭하면 상세 정보가 모달로 열리는지 확인한다.
- 운영자 상세 모달에서도 동일한 템플릿 미리보기와 가로 진행 상태 UI가 보이는지 확인한다.
- 운영자 상세 모달에서 상태 변경과 주문 취소 액션이 기존처럼 동작하는지 확인한다.
- 운영자 화면에서 여러 주문을 체크하고 `N건 다음 상태로` 버튼을 눌렀을 때 선택 주문 상태가 다음 단계로 변경되는지 확인한다.
- 운영자 화면에서 선택 항목 CSV 다운로드와 선택 해제가 동작하는지 확인한다.
