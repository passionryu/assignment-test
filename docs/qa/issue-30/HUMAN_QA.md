# Issue 30 Human QA

## Issue

- #30 `[Lv2 고도화] 기록 선택 상세 보기 및 책 구성 순서 UX 개선`

## 구현 결과

- 기록 선택 단계에 `전체/선택됨/미선택` 상태 필터와 `추억/미션/편지/채팅` 타입 필터를 2줄로 추가했다.
- 기존 `2p` 표기를 `2p 할당`으로 변경하고, hover tooltip에 콘텐츠 타입별 페이지 산정 기준을 표시한다.
- 체크박스 클릭은 선택/해제만 수행하고, 카드 본문 클릭은 상세 보기 modal을 연다.
- 상세 보기 modal은 콘텐츠 타입별로 다른 정보를 표시한다.
- 날짜 순/콘텐츠 순 책 구성 순서를 지원한다.
- 콘텐츠 순 모드에서는 추억 게시글, 미션 인증, 편지, 채팅 타입의 배치 순서를 위/아래 버튼으로 조정할 수 있다.
- 우측 패널에 최종 책 구성 순서를 표시해 미리보기/견적 계산 전에 배치 결과를 확인할 수 있다.
- Human QA 피드백에 따라 기록 카드 오른쪽 눈 아이콘 버튼을 제거하고 카드 본문 hover/focus 상태로 상세 보기 가능성을 표시한다.
- Human QA 피드백에 따라 콘텐츠 순 타입 조정 UI를 카드 확장형에서 즉시 조작 가능한 타입 순서 컨트롤로 변경했다.
- Human QA 피드백에 따라 수량 입력을 브라우저 기본 spinner가 아닌 `- / 숫자 / +` stepper로 변경했다.
- Human QA 피드백에 따라 좌측 콘텐츠 커스텀 카드와 우측 선택 요약 카드 높이를 동일하게 맞추고, 기록 목록은 좌측 카드 내부에서 스크롤되게 했다.
- Human QA 피드백에 따라 우측 `책 구성 순서` 카드의 전체 목록을 제거하고, `전체 순서 보기` 클릭 시 스크롤 가능한 modal로 모든 순서를 확인하게 했다.
- Human QA 피드백에 따라 책 만들기 페이지의 `이전` 버튼을 모두 제거했다.
- Human QA 피드백에 따라 우측 `전체 순서 보기` 버튼을 분홍색 CTA로 변경해 클릭 가능성을 강화했다.
- Human QA 피드백에 따라 기간 선택에서 불러올 콘텐츠 타입을 1개 이상 선택해야 `기록 불러오기`를 누를 수 있게 했다.
- Human QA 피드백에 따라 `기록 불러오기` 클릭 시 최소 3초간 modal spinner와 선택한 방/날짜/콘텐츠 정보를 표시한다.
- Human QA 피드백에 따라 `미리보기/견적 계산` 완료 피드백을 상단 배너가 아닌 modal로 표시하고, 미리보기 페이지로 이동하게 했다.
- Human QA 피드백에 따라 `콘텐츠 순` 타입 조정 컨트롤이 기록 목록을 아래로 밀지 않고 목록 위에 겹쳐 표시되게 했다.
- Human QA 피드백에 따라 방 선택 화면을 `한 방 = 한 줄` 형태의 세로 목록으로 변경했다.
- Human QA 피드백에 따라 기간 선택 화면에 홈 화면과 같은 기록 캘린더를 추가하고, 캘린더에서 날짜 2개를 눌러 시작일/종료일을 정할 수 있게 했다.
- Human QA 피드백에 따라 불러올 콘텐츠 타입 선택 박스를 더 크고 넓은 카드형 UI로 변경했다.
- Human QA 피드백에 따라 `기록 불러오기` 버튼을 기간 선택 카드 하단의 가로형 분홍 CTA로 이동했다.

## Human QA List

- `추억을 책으로 소장 > 책 만들기`에서 방, 상품을 선택한 뒤 기간 선택 단계로 이동한다.
- 방 선택 단계에서 각 방이 한 줄씩 세로로 나열되고, 방 타입/방 이름/구성원 수/책 후보 기록 수가 한 줄 카드 안에서 읽히는지 확인한다.
- 기간 선택 단계에서 캘린더가 보이고 날짜별 채팅/미션/추억/편지 아이콘이 표시되는지 확인한다.
- 캘린더에서 첫 날짜를 누르면 시작일과 종료일이 같은 날짜로 설정되고, 두 번째 날짜를 누르면 빠른 날짜가 시작일, 늦은 날짜가 종료일로 설정되는지 확인한다.
- 날짜 input을 직접 바꿔도 캘린더 선택 범위와 단계 요약이 함께 갱신되는지 확인한다.
- 시작일/종료일만 선택하고 콘텐츠 타입을 하나도 선택하지 않으면 `기록 불러오기` 버튼이 비활성화되는지 확인한다.
- `추억 게시글/미션 인증/편지/채팅` 콘텐츠 타입 카드가 기간 선택 카드 폭 안에서 크게 보이고, 선택/해제 상태가 명확한지 확인한다.
- `추억 게시글/미션 인증/편지/채팅` 중 1개 이상 선택하면 `기록 불러오기` 버튼이 활성화되는지 확인한다.
- `기록 불러오기` 버튼이 시작일/종료일 input 옆이 아니라 기간 선택 카드 하단에 가로로 길게 표시되는지 확인한다.
- `기록 불러오기`를 누르면 최소 3초간 modal이 열리고 `선택한 방`, `선택한 날짜`, `선택한 콘텐츠`, `잠시만 기다려 주세요` 문구가 표시되는지 확인한다.
- 콘텐츠 타입을 일부만 선택한 경우 기록 선택 단계에 해당 타입 후보만 불러와지는지 확인한다.
- 기록 선택 단계에서 `2p 할당` 표기가 보이고 hover 시 페이지 산정 기준 tooltip이 보이는지 확인한다.
- 체크박스를 누르면 선택 수와 페이지 수만 바뀌고 상세 modal은 열리지 않는지 확인한다.
- 기록 카드 오른쪽 눈 아이콘이 제거됐고, 카드 본문 hover/focus 시 배경/테두리 변화가 보이는지 확인한다.
- 카드 본문을 누르면 상세 modal이 열리는지 확인한다.
- 추억 게시글, 미션 인증, 편지, 채팅을 각각 눌러 타입별 상세 정보가 다르게 보이는지 확인한다.
- 필터 윗줄에 `전체/선택됨/미선택`, 아랫줄에 `추억/미션/편지/채팅`이 보이는지 확인한다.
- `전체/선택됨/미선택/추억/미션/편지/채팅` 필터가 각 기록 목록을 올바르게 좁히는지 확인한다.
- `날짜 순`에서는 오래된 기록 기준으로 책 구성 순서가 표시되는지 확인한다.
- `콘텐츠 순`에서는 별도 `순서 설정` 버튼 없이 바로 위/아래 버튼이 보이고, 타입 배치 순서를 바꿀 수 있는지 확인한다.
- `콘텐츠 순` 타입 조정 컨트롤이 열려도 아래 기록 카드 목록이 아래로 밀리지 않고, 컨트롤이 목록 위에 겹쳐 보이는지 확인한다.
- 좌측 콘텐츠 커스텀 카드와 우측 선택 요약 카드의 세로 높이가 동일하고, 좌측 기록 목록은 카드 내부에서 스크롤되는지 확인한다.
- 우측 `책 구성 순서` 카드는 한 줄 요약과 분홍색 `전체 순서 보기` 버튼만 유지되는지 확인한다.
- `전체 순서 보기`를 누르면 스크롤 가능한 modal이 열리고, 선택한 모든 기록 순서를 확인할 수 있는지 확인한다.
- 순서를 바꾼 뒤 `전체 순서 보기` modal과 미리보기/견적 계산 결과의 콘텐츠 순서가 같은지 확인한다.
- 수량 입력이 `- / 숫자 / +` stepper로 보이고, `+` 클릭 시 증가, `-` 클릭 시 감소, 최소 1/최대 20 제한이 유지되는지 확인한다.
- `미리보기/견적 계산`을 누르면 상단 성공 배너가 아니라 완료 modal이 뜨고, 뒤 화면은 미리보기 페이지로 이동했는지 확인한다.
- 책 만들기 페이지의 상품 선택, 기간 선택, 기록 선택, 미리보기 단계에 `이전` 버튼이 보이지 않는지 확인한다.
