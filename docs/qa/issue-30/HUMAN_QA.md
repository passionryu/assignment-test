# Issue 30 Human QA

## Issue

- #30 `[Lv2 고도화] 기록 선택 상세 보기 및 책 구성 순서 UX 개선`

## 구현 결과

- 기록 선택 단계에 전체/추억/미션/편지/채팅/선택됨 필터를 추가했다.
- 기존 `2p` 표기를 `2p 할당`으로 변경하고, hover tooltip에 콘텐츠 타입별 페이지 산정 기준을 표시한다.
- 체크박스 클릭은 선택/해제만 수행하고, 카드 본문 또는 눈 아이콘 클릭은 상세 보기 modal을 연다.
- 상세 보기 modal은 콘텐츠 타입별로 다른 정보를 표시한다.
- 날짜 순/콘텐츠 순 책 구성 순서를 지원한다.
- 콘텐츠 순 모드에서는 추억 게시글, 미션 인증, 편지, 채팅 타입의 배치 순서를 위/아래 버튼으로 조정할 수 있다.
- 우측 패널에 최종 책 구성 순서를 표시해 미리보기/견적 계산 전에 배치 결과를 확인할 수 있다.

## Human QA List

- `추억을 책으로 소장 > 책 만들기`에서 방, 상품, 기간을 선택한 뒤 `기록 불러오기`를 누른다.
- 기록 선택 단계에서 `2p 할당` 표기가 보이고 hover 시 페이지 산정 기준 tooltip이 보이는지 확인한다.
- 체크박스를 누르면 선택 수와 페이지 수만 바뀌고 상세 modal은 열리지 않는지 확인한다.
- 카드 본문 또는 눈 아이콘을 누르면 상세 modal이 열리는지 확인한다.
- 추억 게시글, 미션 인증, 편지, 채팅을 각각 눌러 타입별 상세 정보가 다르게 보이는지 확인한다.
- `전체/추억/미션/편지/채팅/선택됨` 필터가 각 기록 목록을 올바르게 좁히는지 확인한다.
- `날짜 순`에서는 오래된 기록 기준으로 책 구성 순서가 표시되는지 확인한다.
- `콘텐츠 순`에서는 타입 순서가 표시되고, 위/아래 버튼으로 타입 배치 순서를 바꿀 수 있는지 확인한다.
- 순서를 바꾼 뒤 우측 `책 구성 순서` 패널과 미리보기/견적 계산 결과의 콘텐츠 순서가 같은지 확인한다.
