## curl 검증

### 메시지 목록 조회

```bash
curl -sS -H 'X-Member-Id: 1' \
  'http://localhost:8080/api/rooms/1/chat/messages'
```

결과:

- HTTP 200
- `roomId=1`
- `roomName=우리 둘의 100일`
- 메시지 목록 반환 확인

### 메시지 작성

```bash
curl -sS -H 'Content-Type: application/json' -H 'X-Member-Id: 1' \
  -d '{"body":"편지를 같이 남겨보자"}' \
  'http://localhost:8080/api/rooms/1/chat/messages'
```

결과:

- HTTP 200
- 사용자 메시지 1개 저장
- `기록방 AI` 응답 1개 저장
- 로컬 placeholder API key 상태에서는 GPT 호출을 건너뛰고 fallback 응답 저장

### 검색

```bash
curl -sS -H 'X-Member-Id: 1' \
  'http://localhost:8080/api/rooms/1/chat/search?keyword=%EC%B1%85'
```

결과:

- HTTP 200
- 검색어 `책`
- 검색 결과 반환 확인

### Edge Case: 빈 메시지

```bash
curl -sS -o /tmp/chat_empty_body.json -w '%{http_code}' \
  -H 'Content-Type: application/json' -H 'X-Member-Id: 1' \
  -d '{"body":"   "}' \
  'http://localhost:8080/api/rooms/1/chat/messages'
```

결과:

- HTTP 400
- `CHAT_MESSAGE_REQUIRED`
- `메시지를 입력해 주세요.`

## 빌드 검증

```bash
cd service/server && ./gradlew build
cd service/client && npm run build
docker compose -f service/infra/docker-compose.yml up --build -d app-server app-client
```

결과:

- Backend Gradle build: PASS
- Frontend TypeScript/Vite build: PASS
- Docker Compose rebuild: PASS
- `http://localhost:8080/actuator/health`: `{"status":"UP"}`
- `http://localhost:5173`: HTTP 200

## 비고

- 실제 OpenAI API key는 repo root의 `.env`에 직접 입력한다.
- `.env`는 `.gitignore`에 의해 커밋되지 않는다.
- `OPENAI_API_KEY`가 없거나 placeholder이면 외부 GPT 호출을 생략하고 fallback 응답을 사용한다.
