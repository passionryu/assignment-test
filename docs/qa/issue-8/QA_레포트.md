# Issue #8 QA 레포트

## QA 상태

- AI QA 유형: Smoke + Focused API 검증
- Playwright E2E: 미실행
- Human QA: 피드백 반영 후 재확인 대기

## 확인한 것

- 방 고유 화면의 `채팅` 메뉴에서 실제 채팅 화면으로 이동한다.
- 채팅 화면에서 날짜 구분선이 표시된다.
- 메시지를 입력하고 `보내기`를 누르면 사용자 메시지와 방 구성원 랜덤 응답 1~3개가 추가된다.
- 검색어 입력 후 `검색`을 누르면 검색 결과가 표시된다.
- 검색 결과를 누르면 해당 메시지 위치로 이동한다.
- 빈 메시지 전송은 서버에서 거부한다.
- API key가 없는 로컬 환경에서는 외부 API를 호출하지 않고 방 구성원 랜덤 응답으로 시연한다.

## Human QA 피드백 반영

- 한 번 전송 시 중복 메시지가 생기지 않도록 프론트 전송 잠금을 추가했다.
- 기존 `기록방 AI` fallback 문구를 제거하고, 로컬 시드 실행 시 과거 fallback 문구도 삭제한다.
- 방 메인 화면의 `최근 대화` 카드 안에서 메시지를 입력하고 보낼 수 있게 했다.
- 방 메인 `최근 대화`, 채팅 화면, 대화 검색 영역은 화면 높이 안에서 내부 스크롤로 동작하게 조정했다.

## Human QA 요청

아래 항목을 `http://localhost:5173`에서 확인한다.

1. 사이드바에서 `우리 둘의 100일`을 펼친다.
2. 방 이름을 클릭해 방 메인 화면으로 이동한다.
3. `최근 대화` 카드 안에서 메시지를 입력하고 `보내기`를 한 번 누른다.
4. 내 메시지가 한 번만 추가되고, 방 구성원 답장 1~3개가 이어지는지 확인한다.
5. `기록방 AI`의 기존 fallback 문구가 새로 생성되지 않는지 확인한다.
6. `채팅` 메뉴로 이동해 채팅 목록이 화면 안에서 내부 스크롤되는지 확인한다.
7. 대화 검색 패널도 채팅 화면 높이와 맞고 내부 스크롤되는지 확인한다.
8. 검색창에 `책` 또는 `사진`을 입력하고 `검색`을 누른다.
9. 검색 결과를 클릭했을 때 해당 메시지 위치로 스크롤 이동하는지 확인한다.
10. 빈 메시지를 보내려고 할 때 오류 메시지가 보이는지 확인한다.

## 주의

- 실제 GPT 응답을 확인하려면 repo root의 `.env`에 `OPENAI_API_KEY`를 입력한 뒤 서버를 재시작해야 한다.
- API key가 없으면 방 구성원 랜덤 응답으로 시연되므로 GPT 실제 응답 품질 QA는 별도 확인이 필요하다.
