# Issue #8 QA 레포트

## QA 상태

- AI QA 유형: Smoke + Focused API 검증
- Playwright E2E: 미실행
- Human QA: 대기

## 확인한 것

- 방 고유 화면의 `채팅` 메뉴에서 실제 채팅 화면으로 이동한다.
- 채팅 화면에서 날짜 구분선이 표시된다.
- 메시지를 입력하고 `보내기`를 누르면 사용자 메시지와 `기록방 AI` 응답이 추가된다.
- 검색어 입력 후 `검색`을 누르면 검색 결과가 표시된다.
- 검색 결과를 누르면 해당 메시지 위치로 이동한다.
- 빈 메시지 전송은 서버에서 거부한다.
- API key가 없는 로컬 환경에서도 fallback AI 응답으로 시연이 가능하다.

## Human QA 요청

아래 항목을 `http://localhost:5173`에서 확인한다.

1. 사이드바에서 `우리 둘의 100일`을 펼친다.
2. `채팅`을 클릭한다.
3. 날짜 구분선과 기존 메시지 목록이 보이는지 확인한다.
4. 메시지 입력창에 `오늘 사진을 책에 넣고 싶어` 같은 문장을 입력하고 `보내기`를 누른다.
5. 내 메시지와 `기록방 AI` 응답이 하단에 추가되는지 확인한다.
6. 검색창에 `책` 또는 `사진`을 입력하고 `검색`을 누른다.
7. 검색 결과를 클릭했을 때 해당 메시지 위치로 스크롤 이동하는지 확인한다.
8. 빈 메시지를 보내려고 할 때 오류 메시지가 보이는지 확인한다.

## 주의

- 실제 GPT 응답을 확인하려면 repo root의 `.env`에 `OPENAI_API_KEY`를 입력한 뒤 서버를 재시작해야 한다.
- API key가 없으면 fallback 응답이 표시되므로 GPT 실제 응답 품질 QA는 별도 확인이 필요하다.
