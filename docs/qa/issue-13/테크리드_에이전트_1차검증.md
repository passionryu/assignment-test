# Issue #13 테크리드 에이전트 1차 검증

- Issue: #13 `[구현] 방 생성 및 초대 MVP 구현`
- 기준 시각: 2026-08-01 KST
- 검증 방식: Docker Compose 재빌드 후 `curl` API 검증

## 구현 API

| API | 목적 | 결과 |
|---|---|---|
| `POST /api/rooms` | 방 생성 | PASS |
| `POST /api/rooms/{roomId}/invitations` | 이메일/전화번호 초대 생성 | PASS |
| `GET /api/room-invitations/pending` | 받은 초대 목록 조회 | PASS |
| `POST /api/room-invitations/{invitationId}/accept` | 초대 수락 | PASS |
| `POST /api/room-invitations/{invitationId}/decline` | 초대 거절 | PASS |
| `GET /api/rooms` | 방 목록 및 초대 대기 수 반영 | PASS |

## Happy Case

| 케이스 | 기대 결과 | 실제 결과 |
|---|---|---|
| 방 생성 | 새 방 생성, 생성자는 `OWNER` | HTTP 200, `role=OWNER` |
| 이메일 초대 | `PENDING` 초대 생성 | HTTP 200, `status=PENDING` |
| 받은 초대 조회 | 초대 대상 회원에게 초대 표시 | HTTP 200, 초대 목록 반환 |
| 초대 수락 | 초대 상태 `ACCEPTED`, 방 멤버 추가 | HTTP 200, 수락 회원의 방 목록에 표시 |
| 전화번호 초대 후 거절 | 초대 상태 `DECLINED` | HTTP 200 |

## Edge Case

| 케이스 | 기대 결과 | 실제 결과 |
|---|---|---|
| 방 이름 blank | 생성 거부 | HTTP 400, `ROOM_NAME_REQUIRED` |
| 지원하지 않는 방 타입 | 생성 거부 | HTTP 400, `ROOM_TYPE_NOT_SUPPORTED` |
| 중복 초대 | 생성 거부 | HTTP 409, `PENDING_INVITATION_EXISTS` |
| 자기 자신 초대 | 생성 거부 | HTTP 400, `INVITEE_SELF_NOT_ALLOWED` |
| 이메일 형식 오류 | 생성 거부 | HTTP 400, `INVITEE_EMAIL_INVALID` |
| 비방장 초대 | 생성 거부 | HTTP 403, `ROOM_OWNER_REQUIRED` |
| 이메일/전화번호 동시 입력 | 생성 거부 | HTTP 400, `INVITEE_CONTACT_ONLY_ONE_ALLOWED` |

cd service/client && npm run build
