# Issue #13 QA 레포트

## QA 상태

- AI QA 유형: Smoke + Focused API 검증
- Playwright E2E: 미실행
- Human QA: 대기

## 확인한 것

- 방 리스트 페이지에서 새 방 만들기 폼이 보인다.
- 방 생성 API가 정상 동작한다.
- 방장인 방에서 이메일 또는 전화번호로 초대를 보낼 수 있다.
- 받은 초대 목록을 조회할 수 있다.
- 초대 수락 시 방 목록에 새 방이 추가된다.
- 초대 거절 시 대기 목록에서 제거된다.
- 주요 실패 케이스는 적절한 한국어 메시지와 HTTP 상태를 반환한다.

## Human QA 요청

아래 항목을 `http://localhost:5173`에서 확인한다.

1. 사이드바에서 `방 리스트`로 이동한다.
2. `새 방 만들기`에서 방 이름, 타입, 설명을 입력하고 방을 생성한다.
3. 생성된 방이 참여 방 목록과 사이드바 방 목록에 반영되는지 확인한다.
4. 생성한 방 카드에서 `minji@example.com` 또는 `010-2222-3333`으로 초대를 보낸다.
5. 중복 초대 시 오류 메시지가 표시되는지 확인한다.
6. 기본 시드의 `초대 받은 방`에서 `민지의 여행 준비방`을 수락하거나 거절한다.
7. 수락 시 방 목록에 새 방이 추가되는지 확인한다.
8. 거절 시 초대 받은 방 목록에서 제거되는지 확인한다.

## Human QA 피드백 반영

- 방 카드의 `선택` 버튼을 제거했다.
- 페이지 우측 상단의 `+ 방 생성` 버튼을 제거하고 카드 내부 `방 생성` 버튼만 남겼다.
- 초대 실패 메시지는 상단 notice가 아니라 모달로 표시한다.
- 초대 테스트용 회원 전화번호 10개를 추가했다.
  - `010-0000-0000`
  - `010-1111-1111`
  - `010-2222-2222`
  - `010-3333-3333`
  - `010-4444-4444`
  - `010-5555-5555`
  - `010-6666-6666`
  - `010-7777-7777`
  - `010-8888-8888`
  - `010-9999-9999`
- 받은 초대 시드는 3개로 보강했다.

## Human QA 추가 피드백 반영 2

- 방장이 아닌 방도 이메일/전화번호 입력창과 초대 버튼을 동일하게 보여준다.
- 방장이 아닌 방의 초대 입력창과 버튼은 비활성화하고 `방장 권한 필요` 안내를 표시한다.
- 초대 성공 메시지를 상단 notice가 아니라 모달로 표시한다.
- 초대 수락/거절 결과 메시지를 상단 notice가 아니라 모달로 표시한다.
- 방 생성 성공/실패 메시지를 상단 notice가 아니라 모달로 표시한다.
