# Issue #13 코드리뷰 에이전트 코드 리뷰

## 검토 결과

| 항목 | 결과 | 메모 |
|---|---|---|
| API 범위 | PASS | #13 범위인 방 생성, 초대, 받은 초대, 수락/거절만 구현했다. |
| 서비스 흐름 | PASS | `RoomService`에서 조회, 검증, 저장, 응답 흐름이 명시적으로 보인다. |
| 도메인 정책 | PASS | 방 생성자는 `OWNER`, 초대는 `OWNER`만 가능하도록 제한했다. |
| 중복/정합성 | PASS | 이미 참여 중인 회원, 중복 대기 초대, 자기 자신 초대를 차단한다. |
| 프론트 연결 | PASS | 방 리스트 화면에서 생성, 초대 입력, 수락/거절을 수행한다. |
| 빌드 | PASS | Backend compile, Frontend build 통과. |

## 수용한 설계 결정

- 초대 대상은 MVP에서 기존 회원만 허용한다.
- 초대 연락처는 이메일 또는 전화번호 중 하나만 받는다.
- 방 상세 관리, 멤버 권한 변경, 강퇴는 #13 범위에서 제외한다.
- 현재 로그인 사용자는 기존 MVP 정책대로 `X-Member-Id` 헤더를 사용한다.

## 잔여 리스크

- 실제 인증/세션이 없으므로 운영용 권한 검증은 이후 인증 이슈에서 보강해야 한다.
- 방 관리 고도화가 없으므로 생성 후 이름/설명 수정은 아직 지원하지 않는다.
- 초대 알림 실시간 반영은 구현하지 않았다.
