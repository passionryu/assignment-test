# Issue 24 Human QA

## Issue

- #24 `[Lv2 구현] 책 주문 생성 및 주문 상태/내역 조회 구현`

## 구현 결과

- 확정된 미리보기에서 책 주문을 생성한다.
- 주문 생성 시 최초 상태는 `PAID`로 저장한다.
- 주문 당시의 방, 상품, 기간, 콘텐츠, 예상 페이지, 견적을 주문 snapshot으로 복사한다.
- 일반 사용자는 본인 진행 주문을 `주문 상태`에서 조회한다.
- 일반 사용자는 완료/취소/오류 주문을 `주문 내역`에서 조회한다.
- 일반 사용자는 본인 주문 상세만 조회할 수 있다.

## Human QA List

- 미리보기 화면에서 `주문 요청하기`를 누른다.
- 주문 확인 모달의 상품, 방, 기간, 콘텐츠 수, 수량, 총액이 미리보기와 같은지 확인한다.
- 주문 생성 후 `주문 상태` 화면으로 이동하는지 확인한다.
- 새 주문이 `주문 요청` 상태로 표시되는지 확인한다.
- 주문 상세에서 주문 당시 선택 콘텐츠와 견적 snapshot이 보이는지 확인한다.
- `주문 내역`에는 `DELIVERED`, `CANCELLED_REFUND`, `ERROR` 같은 종료 주문만 보이는지 확인한다.
- 다른 사용자의 주문은 목록과 상세에서 보이지 않는지 확인한다.
