# Issue 26 Human QA

## Issue

- #26 `[Lv2 구현] 운영자 캐릭터 주문 확인 MVP 구현`

## 구현 결과

- 체험 사용자 선택 화면에 운영자 캐릭터를 추가했다.
- 운영자 캐릭터는 `memberId=100`으로 동작한다.
- 운영자 선택 시 일반 사용자 화면이 아니라 운영자 주문 확인 MVP로 진입한다.
- 운영자는 전체 주문 목록을 조회할 수 있다.
- 운영자는 주문 상세, 상태 필터, 다음 상태 변경, 취소 액션을 수행할 수 있다.
- 일반 사용자 사이드바에는 운영자 메뉴를 노출하지 않는다.
- 별도 관리자 로그인, 정산, 실제 배송 운영은 제외했다.

## Human QA List

- 사용자 선택 화면에서 `운영자` 캐릭터가 보이는지 확인한다.
- 운영자 캐릭터 선택 시 일반 기록방 홈이 아니라 주문 확인 화면으로 진입하는지 확인한다.
- 운영자 화면에서 전체 주문과 주문자 이름이 보이는지 확인한다.
- 상태 필터를 변경하면 목록이 필터링되는지 확인한다.
- 주문 상세에서 상품, 주문자, 방, 콘텐츠 snapshot, 상태 이력이 보이는지 확인한다.
- `PAID` 주문에서 다음 상태 변경이 가능한지 확인한다.
- `PAID` 또는 `PDF_READY` 주문에서 취소가 가능한지 확인한다.
- 일반 사용자 좌측 메뉴에 운영자 확인 메뉴가 보이지 않는지 확인한다.

## 권한 QA

- 일반 사용자로 운영자 API를 호출하면 `403 OPERATOR_ONLY`가 반환되어야 한다.
