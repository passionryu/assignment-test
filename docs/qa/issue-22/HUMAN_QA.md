# Issue 22 Human QA

## Issue

- #22 `[Lv2 구현] 상품 안내 placeholder 및 상품 선택 UI 구현`

## 구현 결과

- 전역 책 메뉴 하위 순서를 `상품 안내`, `책 만들기`, `주문 상태`, `주문 내역`으로 정리했다.
- `상품 안내` 페이지는 상세 기획 전 placeholder로 노출한다.
- `책 만들기` 플로우 안에서 상품 3종 중 하나를 선택한다.
- 상품 선택 UI는 서버의 `book_presets` 값을 기준으로 표시한다.
- 선택한 상품의 `bookSpecUid`와 페이지 범위가 다음 기간/콘텐츠 선택 단계에 전달된다.
- 선택한 콘텐츠 특성에 따라 추천/주의 문구를 표시한다.

## Human QA List

- 좌측 메뉴 최하단에 `추억을 책으로 소장` 전역 디렉토리가 하나만 보이는지 확인한다.
- 하위 메뉴 순서가 `상품 안내`, `책 만들기`, `주문 상태`, `주문 내역`인지 확인한다.
- 일반 사용자 방 하위 메뉴마다 책 메뉴가 중복 표시되지 않는지 확인한다.
- `상품 안내`를 눌렀을 때 상세 정보가 아직 기획중임을 명확히 안내하는지 확인한다.
- `책 만들기`에서 방 선택 후 상품 3종이 모두 표시되는지 확인한다.
- 상품 선택 시 페이지 제한과 안내 문구가 다음 단계에 반영되는지 확인한다.

## UI QA

- 운영자 확인 메뉴는 일반 사용자 좌측 사이드바에 노출되지 않아야 한다.
- 상품명은 유저 친화적 별칭이 아니라 확정된 상품명 중심으로 보여야 한다.
