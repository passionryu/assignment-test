# Issue #9 QA 레포트

## QA 상태

- AI QA 유형: Smoke + Focused API 검증
- Playwright E2E: 미실행
- Human QA: 대기

## 확인한 것

- 사이드바에서 선택 방의 `추억 게시판`으로 이동할 수 있다.
- 추억 게시글 목록이 seed 데이터 기준으로 20개 이상 표시된다.
- 목록은 6개 단위 페이지네이션으로 이동할 수 있다.
- 이미지 URL 입력 대신 파일 선택과 드래그앤드롭으로 이미지를 업로드할 수 있다.
- 업로드된 이미지는 `/uploads/memories/...` 정적 경로로 조회된다.
- 업로드 이미지 경로로 새 추억 게시글을 작성하면 대표 이미지와 `imageCount=1`이 반영된다.
- 게시글 카드를 클릭하면 상세 패널에 대표 이미지, 작성자, 날짜, 본문, 댓글이 표시된다.
- 댓글은 내 댓글과 상대 댓글이 좌/우 말풍선으로 구분된다.
- 댓글이 많아져도 댓글 목록만 내부 스크롤되고 입력창이 계속 아래로 밀리지 않는다.
- 댓글을 작성하면 상세 패널과 목록의 댓글 수가 갱신된다.
- 추억 등록 완료 시 모달이 표시된다.
- 작성자 본인의 추억은 수정/삭제할 수 있다.
- 비이미지 파일, 미참여 방 업로드, 회원 헤더 누락은 서버 검증으로 차단된다.

## Human QA 요청

아래 항목을 `http://localhost:5173`에서 확인한다.

1. 사이드바에서 `우리 둘의 100일`을 펼친 뒤 `추억 게시판`으로 이동한다.
2. `추억 목록`에 게시글이 여러 페이지로 나뉘어 보이는지 확인한다.
3. 페이지 번호/이전/다음 버튼을 눌러 게시글 목록이 이동하는지 확인한다.
4. `추억 남기기` 영역에서 파일 선택 버튼으로 노트북의 이미지 파일을 선택한다.
5. 같은 영역에 이미지 파일을 드래그앤드롭했을 때도 업로드와 미리보기 파일명이 반영되는지 확인한다.
6. 제목, 날짜, 내용까지 입력한 뒤 `추억 등록`을 눌러 새 게시글이 생성되는지 확인한다.
7. 새 게시글 카드와 우측 상세 패널에서 업로드 이미지가 정상 표시되는지 확인한다.
8. 이미지 없이 새 게시글을 등록했을 때 placeholder가 보이는지 확인한다.
9. 제목 또는 내용을 비운 상태로 등록해 오류 메시지가 나오는지 확인한다.
10. `.txt` 같은 비이미지 파일을 업로드했을 때 서버 검증 메시지가 나오는지 확인한다.
11. 추억 카드 하나를 클릭해 우측 상세 패널의 본문과 댓글이 바뀌는지 확인한다.
12. 댓글을 여러 개 작성해도 댓글 영역만 내부 스크롤되고 입력창이 과도하게 아래로 밀리지 않는지 확인한다.
13. 댓글을 작성하고 내 댓글이 오른쪽 말풍선으로 추가되는지 확인한다.
14. 기존 상대 댓글이 왼쪽 말풍선으로 보이는지 확인한다.
15. 새 추억을 등록했을 때 완료 모달이 뜨는지 확인한다.
16. 내가 작성한 추억 상세에서 `수정` 버튼을 눌러 제목/날짜/내용/대표 사진을 변경한다.
17. 수정 완료 후 목록 카드와 우측 상세 패널에 변경 내용이 반영되는지 확인한다.
18. 내가 작성한 추억 상세에서 `삭제` 버튼을 눌러 삭제 확인 모달이 뜨는지 확인한다.
19. 삭제 완료 후 목록에서 해당 추억이 사라지고 다음 추억 상세가 선택되는지 확인한다.
20. 다른 방의 `추억 게시판`으로 이동했을 때 해당 방 기준 목록으로 바뀌는지 확인한다.

## 주의

- 댓글 수정과 삭제는 이번 이슈 범위 밖이다.
- 이미지 업로드는 Lv1 콘텐츠 서비스 검증용 로컬 저장 방식이며, 운영 환경에서는 CDN/스토리지 전환이 필요하다.
- Playwright 영상/스크린샷 evidence는 이번 Focused QA 범위에서는 생성하지 않았다.
