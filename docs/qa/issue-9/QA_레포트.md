# Issue #9 QA 레포트

## QA 상태

- AI QA 유형: Smoke + Focused API 검증
- Playwright E2E: 미실행
- Human QA: 대기

## 확인한 것

- 사이드바에서 선택 방의 `추억 게시판`으로 이동할 수 있다.
- 추억 게시글 목록이 seed 데이터 기준으로 표시된다.
- 게시글 카드를 클릭하면 상세 패널에 대표 이미지, 작성자, 날짜, 본문, 댓글이 표시된다.
- 제목, 날짜, 이미지 URL, 내용을 입력해 새 추억을 등록할 수 있다.
- 이미지 URL이 없는 게시글은 placeholder로 표시된다.
- 댓글을 작성하면 상세 패널과 목록의 댓글 수가 갱신된다.
- 잘못된 입력은 서버 검증 메시지로 차단된다.

## Human QA 요청

아래 항목을 `http://localhost:5173`에서 확인한다.

1. 사이드바에서 `우리 둘의 100일`을 펼친 뒤 `추억 게시판`으로 이동한다.
2. 추억 목록 카드들이 이미지 또는 placeholder와 함께 보이는지 확인한다.
3. 추억 카드 하나를 클릭해 우측 상세 패널의 본문과 댓글이 바뀌는지 확인한다.
4. `추억 남기기` 폼에 제목, 날짜, 이미지 URL, 내용을 입력하고 등록한다.
5. 새 게시글이 목록 최상단 또는 해당 정렬 위치에 반영되고 상세 패널에 선택되는지 확인한다.
6. 이미지 URL을 비우고 새 게시글을 등록했을 때 placeholder가 보이는지 확인한다.
7. 제목 또는 내용을 비운 상태로 등록해 오류 메시지가 나오는지 확인한다.
8. 이미지 URL에 `ftp://...` 값을 넣고 등록해 오류 메시지가 나오는지 확인한다.
9. 선택한 게시글에 댓글을 작성하고 댓글 목록과 댓글 수가 갱신되는지 확인한다.
10. 다른 방의 `추억 게시판`으로 이동했을 때 해당 방 기준 목록으로 바뀌는지 확인한다.

## 주의

- 실제 파일 업로드는 Lv1 범위에서 제외되어 이미지 URL만 지원한다.
- 게시글/댓글 수정과 삭제는 이번 이슈 범위 밖이다.
- curl 검증 중 생성한 QA용 게시글은 soft delete로 정리했다.
