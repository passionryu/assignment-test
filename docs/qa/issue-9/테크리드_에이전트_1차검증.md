## 빌드 및 실행 검증

```bash
cd service/server && ./gradlew compileKotlin
cd service/client && npm run build
docker compose -f service/infra/docker-compose.yml up --build -d
docker compose -f service/infra/docker-compose.yml ps
curl -i http://localhost:8080/actuator/health
curl -i http://localhost:5173
```

결과:

- Backend Kotlin compile: PASS
- Frontend TypeScript/Vite build: PASS
- Docker Compose 실행 상태: server/client/db 모두 UP
- `http://localhost:8080/actuator/health`: HTTP 200, `{"status":"UP"}`
- `http://localhost:5173`: client container 노출 확인
- `GET /api/rooms/1/memories`: seed 게시글 20개 이상 반환 확인

## 데이터 정리

- curl 작성/수정/삭제 검증 중 생성한 QA용 게시글은 `QA_UPLOAD_MEMORY_TEST`, `QA_EDIT_DELETE_MEMORY_TEST` title로 만들었다.
- 검증 후 삭제 API 또는 `memory_posts.deleted_at` 갱신으로 화면 QA seed와 섞이지 않도록 soft delete 처리했다.
