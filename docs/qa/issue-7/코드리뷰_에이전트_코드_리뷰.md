## Security 생략 사유

- 신규 기능은 조회 전용 캘린더 집계와 프론트 표시 기능이다.
- 회원 정보, 인증, 권한, 주문, secret, 외부 API 연동을 변경하지 않았다.
- `memberId`는 기존 `CurrentMemberResolver`를 통해 확인하고, 조회는 참여 중인 방 membership 기준으로 제한했다.

## 남은 리스크

- 상세 기록 화면은 아직 placeholder이므로 `기록 보기`는 해당 기능 탭으로 이동하는 수준이다.
- 실제 기록 상세 리스트 구현 시 각 도메인 API의 권한 검증을 다시 리뷰해야 한다.
