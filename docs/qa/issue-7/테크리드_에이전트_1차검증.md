# Issue #7 테크리드 에이전트 1차검증

- 대상 이슈: #7 `[구현] 캘린더 및 선택 날짜 요약 구현`
- 대상 브랜치: `feature-7`
- 검증 수준: curl 1차 검증
- 전체 결과: PASS

## 구현 범위

- `GET /api/calendar?month=yyyy-MM&roomId={optional}` API 추가
- 현재 회원이 참여 중인 방의 채팅, 추억, 미션 인증, 편지 기록을 날짜별로 집계
- 방 필터가 있는 경우 해당 방의 기록만 집계
- 로컬 시드 데이터에 현재 월의 여러 날짜 활동 추가
- Asia/Seoul 기준으로 시드 날짜와 기본 월 계산

## curl 검증

| 케이스 | 명령 | 기대 결과 | 결과 |
| --- | --- | --- | --- |
| Health | `curl -s http://localhost:8080/api/health` | `status=UP`, `database=UP` | PASS |
| 월별 전체 조회 | `curl -s -H 'X-Member-Id: 1' "http://localhost:8080/api/calendar?month=$(date +%Y-%m)"` | 현재 월 날짜별 활동 반환 | PASS |
| 방 필터 조회 | `curl -s -H 'X-Member-Id: 1' "http://localhost:8080/api/calendar?month=$(date +%Y-%m)&roomId=1"` | 1번 방 활동만 반환 | PASS |
| 다른 방 필터 조회 | `curl -s -H 'X-Member-Id: 1' "http://localhost:8080/api/calendar?month=$(date +%Y-%m)&roomId=3"` | 3번 방 활동만 반환 | PASS |
| 잘못된 월 형식 | `curl -i -H 'X-Member-Id: 1' "http://localhost:8080/api/calendar?month=bad"` | HTTP 400, `INVALID_MONTH` | PASS |
| 회원 헤더 누락 | `curl -i "http://localhost:8080/api/calendar?month=$(date +%Y-%m)"` | HTTP 401, `MEMBER_ID_REQUIRED` | PASS |

## 확인된 대표 응답

- 전체 조회는 `2026-08-01`, `2026-08-10`, `2026-08-17`, `2026-08-28` 활동을 반환했다.
- `roomId=1` 조회는 `우리 둘의 100일` 활동만 반환했다.
- `roomId=3` 조회는 `여름 프로젝트반` 활동만 반환했다.

## 남은 리스크

- 상세 기록 화면은 #7 범위가 아니므로 기존 placeholder 화면으로 이동한다.
- 실제 상세 리스트 조회는 채팅/추억/미션/편지 개별 이슈에서 구현한다.
