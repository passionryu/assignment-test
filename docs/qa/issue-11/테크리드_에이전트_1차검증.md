# 이슈 11 테크리드 에이전트 1차 검증

## 검증 대상

- 이슈: `#11 [구현] 편지 기능 구현`
- 범위: 선택 방의 편지 작성, 받은 편지함, 보낸 편지함, 편지 상세 조회, 받은 편지 읽음 처리
- 기준 브랜치: `feature-11`
- 기준 시각: 2026-08-02 KST

## API 구현 목록

| API | 목적 |
|---|---|
| `GET /api/rooms/{roomId}/letters?box=RECEIVED&page={page}&size={size}` | 선택 방의 받은 편지함을 서버 페이지네이션으로 조회 |
| `GET /api/rooms/{roomId}/letters?box=SENT&page={page}&size={size}` | 선택 방의 보낸 편지함을 서버 페이지네이션으로 조회 |
| `POST /api/rooms/{roomId}/letters` | 같은 방 구성원에게 편지 전송, 서버 전송 시점 기준 날짜/시간 자동 저장 |
| `GET /api/rooms/{roomId}/letters/{letterId}` | 편지 상세 조회 및 받은 편지 읽음 처리 |

## 검증 메모

- 편지 상세 조회 시 받은 편지는 서버에서 `readAt`을 갱신한다.
- 편지 전송 시 수신자에게 `LETTER` 타입 알림을 생성하며, 날짜 입력 없이 서버 기준 날짜/시간을 저장한다.
- 같은 방 구성원이 아닌 사용자는 수신자로 지정할 수 없다.
- 편지함 화면은 받은 편지함/보낸 편지함을 분리하고, 최신순 목록을 고정 높이 스크롤 영역에서 서버 페이지네이션 기준으로 최초 10개 조회 후 `더 보기`로 다음 페이지를 요청한다.
- 화면 QA는 `http://localhost:5173/`에서 진행한다.
