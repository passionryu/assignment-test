# Issue 29 Human QA

## Issue

- #29 `[Lv2 고도화] 책 만들기 단계별 화면 전환 UI 개선`

## 구현 결과

- 책 만들기 화면을 단계형 wizard UI로 변경했다.
- 진행 단계는 `방 선택 -> 상품 선택 -> 기간 선택 -> 기록 선택 -> 미리보기` 순서다.
- 각 단계를 완료하면 다음 단계 화면으로 자동 이동한다.
- 현재 단계 본문만 화면에 표시하고, 다른 단계 내용은 동시에 길게 노출하지 않는다.
- 이전 버튼과 완료 단계 재진입을 지원한다.
- 책 만들기 상단 선택 요약 카드 영역은 Human QA 피드백에 따라 제거했다.

## Human QA 확인 항목

- `추억을 책으로 소장 > 책 만들기` 진입 시 방 선택 단계만 노출된다.
- 방을 선택하면 상품 선택 단계로 자동 이동한다.
- 상품을 선택하면 기간 선택 단계로 자동 이동한다.
- `기록 불러오기` 후 기록 선택 단계로 자동 이동한다.
- `미리보기/견적 계산` 후 미리보기와 예상 견적 단계로 이동한다.
- 이전 버튼과 상단 stepper 재진입이 동작한다.
- 책 만들기 상단의 중복 선택 요약 카드가 제거됐다.
- 기존 주문 요청 흐름은 유지된다.
