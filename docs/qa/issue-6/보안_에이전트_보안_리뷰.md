## Security Findings

| ID | Severity | Risk | Status | Description |
| --- | --- | --- | --- | --- |
| SEC-006-001 | MINOR | MVP auth limitation | ACCEPTED | `X-Member-Id`는 로컬 MVP 식별 헤더다. 기존 프로젝트 정책과 동일하며, 누락/잘못된 값은 오류로 처리된다. 실제 배포 인증으로 재사용하면 안 된다. |
| SEC-006-002 | MINOR | Target fallback URL | ACCEPTED | target 정보가 없으면 URL이 `/`로 생성된다. 외부 URL은 아니므로 open redirect 위험은 낮지만, 상세 삭제/접근 불가 상태가 생기면 프론트에서 명시 안내를 추가한다. |

BLOCKER 또는 CRITICAL 보안 이슈는 없다.
