## Findings

| ID | Severity | Area | Status | Description |
| --- | --- | --- | --- | --- |
| CR-006-001 | MINOR | Paging response metadata | ACCEPTED | `GET /api/notifications`는 `page`, `size`, `hasNext` metadata 없이 `items`만 반환한다. 현재 전체 보기 모달은 첫 페이지 목록 표시만 사용하므로 기능 동작은 가능하다. 후속 load-more/pagination UI를 넣을 때 metadata를 추가한다. |
| CR-006-002 | MINOR | Target URL query naming | ACCEPTED | target URL은 `/rooms/{roomId}/{feature}?targetId={id}` 형태로 생성된다. 기준 문서 예시는 `focusMessageId`, `focusSubmissionId`처럼 타입별 query name을 제안하지만, 현재 프론트는 상세 focus 미구현 상태라 target type 기준 화면 이동만 수행한다. |
| CR-006-003 | MINOR | Notification type naming | ACCEPTED | seed는 미션 진행률 타입을 `MISSION_PROGRESS`로 사용한다. 기준 문서의 `MISSION_APPROVAL_RATE`와 명칭 차이가 있으나 UI에서는 미션 타입으로 안전하게 fallback된다. 타입 확정 시 enum/문서/seed를 정리한다. |
