# Issue 23 Human QA

## Issue

- #23 `[Lv2 구현] 템플릿 기반 책 미리보기와 예상 페이지/견적 계산 구현`

## 구현 결과

- 선택한 방, 상품, 기간, 콘텐츠를 기반으로 템플릿 미리보기를 생성한다.
- 미리보기는 표지/구성 요약/대표 페이지 목록을 반환한다.
- 선택 콘텐츠의 예상 페이지 수를 계산한다.
- 상품의 포함 페이지와 추가 페이지 단가를 기준으로 mock 견적을 계산한다.
- 수량 변경 시 총 예상 금액이 다시 계산된다.
- 실제 PDF 생성과 인쇄 규격 검증은 제외했다.

## Human QA List

- 콘텐츠 선택 후 `미리보기 만들기`를 실행한다.
- 미리보기 화면에서 책 제목, 방 이름, 상품명, 기간이 이전 단계와 일치하는지 확인한다.
- 대표 페이지 목록이 선택 콘텐츠 순서와 맞게 표시되는지 확인한다.
- 예상 페이지 수가 상품의 최소/최대 범위 안에 있는지 확인한다.
- 수량을 변경했을 때 총 예상 금액이 갱신되는지 확인한다.
- 최소 페이지보다 적은 콘텐츠 구성은 템플릿 기본 페이지로 보정되는지 확인한다.
- 최대 페이지를 초과한 구성은 주문 단계로 넘어가지 못하는지 확인한다.

## 제외 확인

- PDF 다운로드/업로드가 필수 흐름으로 보이지 않아야 한다.
- 실제 인쇄 파일 검수 상태가 미리보기 단계에서 요구되지 않아야 한다.
