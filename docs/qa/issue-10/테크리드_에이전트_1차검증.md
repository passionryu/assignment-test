## 빌드 및 실행 검증

```bash
cd service/server && ./gradlew compileKotlin
cd service/client && npm run build
docker compose -f service/infra/docker-compose.yml up --build -d app-server app-client
curl -i http://localhost:8080/actuator/health
curl -i http://localhost:5173
```

결과:

- Backend Kotlin compile: PASS
- Frontend TypeScript/Vite build: PASS
- Docker Compose 실행 상태: server/client/db 모두 UP
- `http://localhost:8080/actuator/health`: HTTP 200, `{"status":"UP"}`
- `http://localhost:5173`: client container 노출 확인
