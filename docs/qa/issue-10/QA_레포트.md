# Issue #10 QA 레포트

## QA 상태

- AI QA 유형: Smoke + Focused API 검증
- Playwright E2E 영상: 미생성
- Human QA: 대기

## 확인한 것

- 사이드바에서 선택 방의 `미션 인증` 화면으로 이동할 수 있다.
- 방 타입별 기본 미션 20개가 시드로 제공된다.
- 기본 미션은 사진 인증이 가능한 문장으로 구성되어 있다.
- `우리 둘의 100일` 화면에서 미션 카드 20개가 표시된다.
- 미션 상태는 `진행 중`, `승인 대기`, `완료`로 구분된다.
- 커스텀 미션을 제목/설명으로 추가할 수 있다.
- 인증 제출은 사진 파일 업로드가 필수다.
- 파일 선택/드래그앤드롭 영역이 표시된다.
- 인증 요청 후 미션 상태가 승인 대기로 변경된다.
- 커플 방은 상대 동의 1회로 완료된다.
- 가족/학급·동아리 방은 방장 승인 또는 과반 동의 정책을 API 응답으로 반환한다.
- 본인 인증에 본인이 동의하는 것은 서버에서 차단된다.
- 비이미지 파일 업로드는 서버에서 차단된다.

## Human QA 요청

아래 항목을 `http://localhost:5173`에서 확인한다.

1. 사이드바에서 `우리 둘의 100일`을 펼친 뒤 `미션 인증`으로 이동한다.
2. 기본 미션 목록이 20개 보이는지 확인한다.
3. 미션 카드 클릭 시 우측 상세 패널이 해당 미션 내용으로 바뀌는지 확인한다.
4. `승인 대기`, `완료`, `진행 중` 상태 표시가 자연스럽게 보이는지 확인한다.
5. `커스텀 미션 추가`에서 제목/설명을 입력하고 `미션 추가`를 눌러 목록에 추가되는지 확인한다.
6. 인증 제출 영역에서 이미지 파일을 선택하거나 드래그앤드롭해 업로드되는지 확인한다.
7. 인증 내용과 날짜를 입력하고 제출하면 해당 미션이 `승인 대기`로 바뀌는지 확인한다.
8. 사진 없이 제출할 때 오류 안내가 나오는지 확인한다.
9. `.txt` 같은 비이미지 파일 업로드가 차단되는지 확인한다.
10. 민지가 올린 `오늘의 산책 사진` 인증에서 `인증 동의`를 누르면 완료 상태로 바뀌는지 확인한다.
11. `7월 가족`, `여름 프로젝트반` 방으로 이동해 방 타입별 미션 목록과 완료 정책 문구가 바뀌는지 확인한다.

## 주의

- 미션 수정/삭제, 반려, 동의 취소는 이번 이슈 범위 밖이다.
- AI QA는 토큰 절약 정책에 따라 Full E2E가 아니라 Smoke + Focused API 검증으로 수행했다.
