# Issue 21 Human QA

## Issue

- #21 `[Lv2 구현] 책 만들기 방/기간/콘텐츠 선택 API/UI 구현`

## 구현 결과

- 책 만들기는 방 1개 선택에서 시작한다.
- 상품 선택 후 기간을 입력하면 해당 기간의 추억 게시글, 미션 인증, 편지가 자동으로 불러와진다.
- 채팅은 기본 자동 포함하지 않고, 사용자가 필요한 경우 별도 추가 대상으로 다루는 정책을 유지한다.
- 기간 안 콘텐츠는 기본 선택 후보로, 기간 밖 콘텐츠는 추가 후보로 분리된다.
- 선택 콘텐츠는 서버에서 방 접근 권한과 콘텐츠 접근 권한을 검증한다.
- 중복 콘텐츠, 빈 콘텐츠, 잘못된 기간, 접근 불가 콘텐츠는 API에서 거부한다.
- 상품별 페이지 제한 상태를 계산해 다음 단계 진행 가능 여부를 판단한다.

## Human QA List

- 일반 사용자로 접속해 `추억을 책으로 소장 > 책 만들기`에 진입한다.
- 첫 단계에서 방을 하나만 선택할 수 있는지 확인한다.
- 상품을 선택한 뒤 기간을 지정하고 `기록 불러오기`를 실행한다.
- 기간 안의 추억 게시글, 미션 인증, 편지가 자동으로 표시되는지 확인한다.
- 기간 밖 콘텐츠가 추가 후보로 분리되어 필요한 항목만 더할 수 있는지 확인한다.
- 콘텐츠 체크를 해제하면 선택 요약과 예상 페이지 수가 갱신되는지 확인한다.
- 페이지 수가 상품 제한을 초과하면 다음 단계로 이동할 수 없는지 확인한다.
- 비공개 편지는 현재 사용자에게 접근 권한이 있는 것만 후보로 보이는지 확인한다.

## 권한 QA

- 참여하지 않은 방의 `roomId`로 후보 조회를 시도하면 실패해야 한다.
- 다른 사용자의 비공개 편지 `sourceId`를 preview 요청에 넣으면 실패해야 한다.
